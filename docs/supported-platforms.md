# 💻 Supported Platforms

Validated source/target policies in `0.1.0-beta.1`:

- **Ubuntu 24.04 to Ubuntu 26.04**: primary diagnostic path.
- **Ubuntu 22.04 to Ubuntu 24.04**: secondary diagnostic path.
- **Pop!_OS 24.04 and Ubuntu derivatives**: detection-only.

> [!NOTE]
> Target-release dependency simulation was not performed. Results do not prove that a release upgrade will succeed.

> [!WARNING]
> Do not claim ARM64, Secure Boot, DKMS build or QEMU validation unless those tests have been run in the target environment.
