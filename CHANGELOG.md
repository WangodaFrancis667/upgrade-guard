# 📝 Changelog

All notable changes to **Upgrade Guard** will be documented in this file.

## [0.1.0-beta.1]

### 🌟 Added
- Initial read-only CLI.
- Platform, package, source, storage, kernel, DKMS, Secure Boot and reboot collectors.
- Required finding IDs `UG-REL-001` through `UG-RBT-001`.
- Text and JSON reporting, schema, Debian metadata and fixture tests.
- Bounded non-shell process contracts, container-limited evidence, Docker `22.04`/`24.04`/`26.04` validation, non-native Debian source packaging, Bash completion and Launchpad release guidance.
